## V5 Doom

The Doom engine is integrated into the VEXcode dashboard project in `CLABKERDEPORTATION`. Build and upload that project, copy [`doom1.wad`](VexV5Doom/doom1.wad) to a FAT32 microSD card, and insert the card into the Brain. Open the DOOM tab and tap **START DOOM** while the robot is disabled. Use the controller to play; touch any sidebar tab to pause and return to the dashboard.

The original PROS project is also kept in [`VexV5Doom`](VexV5Doom/README.md). The integrated VEXcode version uses the same engine sources with a VEX screen and controller adapter. Sound and multiplayer are unsupported.
